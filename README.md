# piece-of-tech.github.io

Website for Piece of Tech LLC, served at https://pieceoftech.app by GitHub Pages.
Project repos in this organization (for example `dinner-party`) are served beneath it, e.g. `/dinner-party/`.

The `CNAME` file holds the custom domain. Do not delete it.

Pages: `/` (company home), `/apps/gettoit/`, `/apps/dinner-party/`, `/about/`.
Shared styles live in `assets/site.css`. `/dinner-party/` is the Dinner Party
privacy policy from the separate `dinner-party` repo, so the app page lives at
`/apps/dinner-party/` instead.
